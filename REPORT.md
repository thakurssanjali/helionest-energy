# Project Report: Autonomous AI Sales Voice Agent ("Priya" for HelioNest Energy)

**Problem.** Small and mid-size Indian sales teams (solar, real estate, EdTech) lose leads because enquiries arrive at all hours, reps spend most of their time on unqualified calls, and details never reach the CRM. HelioNest Energy (a fictional rooftop-solar company in Punjab) gets hundreds of enquiries a month about price, subsidy and installation.

**Solution.** A voice AI sales assistant that answers or returns calls 24/7 in English, Hindi or Hinglish. It answers from company documents (RAG), qualifies the lead (BANT), books a free site survey, updates the CRM, hands off to a human when needed, and gives the manager a summary, sentiment and score for every call.

**End-to-end workflow (working).** Caller speaks → browser voice detection ends the turn → **Groq Whisper** transcribes → **GPT-OSS-120B** agent calls tools (`search_knowledge_base`, `update_lead`, `check_available_slots`, `book_site_survey`, `request_human_callback`, `end_call`) → reply spoken by **Groq Orpheus** (English) or the browser voice (Hindi) → after hang-up, one LLM call produces JSON (summary, needs, objections, per-turn sentiment, outcome, next action) → lead re-scored → dashboard. Outbound mode: a website enquiry creates a lead, and Priya calls it back with context.

**Tech stack.** React + Tailwind (call UI, VAD, barge-in, dashboard) · FastAPI (Python) · Groq API (Whisper large-v3, GPT-OSS-120B with 20B fallback, Orpheus TTS) · RAG with bge-small embeddings (fastembed/ONNX) blended with BM25 · Render Key Value (Redis) for leads, calls, sessions and bookings · browser localStorage for visitor memory · Docker on Render.

**Key design decisions.** (1) The **LLM extracts facts while code computes the score**: BANT points are consistent, explainable and auditable. (2) **Facts come only from RAG**, and only fixed offers can be promised, which prevents made-up prices. (3) **Small context**: only the last 12 messages plus a live lead snapshot, which keeps latency and tokens low. (4) **Atomic slot booking** (Redis `SETNX`) prevents double booking. (5) **Graceful degradation**: 120B → 20B on rate limits, Groq TTS → browser voice, vector → BM25 retrieval.

**Scalability to 1,00,000 users.** One lakh users does not mean one lakh simultaneous calls. At an assumed 2% peak, that is about 2,000 concurrent calls. The API is **stateless** (all call state is in Redis), so it scales horizontally behind a load balancer with autoscaling. Next steps: Redis cluster, Postgres for the durable CRM, pgvector or Qdrant when the knowledge base grows, a queue (Celery/RQ) for post-call analysis, streaming STT/TTS over WebSockets for sub-second replies, telephony (Twilio/Exotel media streams) feeding the same agent, paid API tiers, multi-provider fallback, and a CDN for the frontend.

**Security and compliance.** API keys stay on the server only; HTTPS; Redis reachable only on Render's private network; session TTL (2 h); upload size limits. The agent discloses that it is AI, never asks for OTP, Aadhaar or bank details, honours "do not call", and collects only what the enquiry needs. Production adds: consent capture and a retention/deletion policy (DPDP Act 2023), TRAI DND checks for outbound calls, admin login for the dashboard, rate limiting and audit logs.

**Operational cost (estimate, per 4-minute call; assumptions stated).** STT ≈ 2 min of caller audio at $0.111/hr ≈ ₹0.3 · LLM ≈ 55K input + 4K output tokens at $0.15 / $0.75 per M ≈ ₹1 · TTS ≈ 1,500 characters ≈ ₹2–5 (provider-dependent) → **about ₹4–7 per call** before telephony (assumed about ₹0.5–1/min). An assumed human sales rep at ₹25,000/month handling about 400 calls costs about **₹60+ per call**, and only during office hours. Hosting for the demo is free (Render free tier + Groq free tier).

**Commercial model.** A SaaS subscription per company (for example a base fee plus per-minute usage), sold to solar installers, real-estate developers and EdTech firms. Value: instant 24/7 response, about 10× lower cost per qualified lead, and complete CRM data.

**Limitations and next steps.** Groq's free tier has tight token-per-minute limits; Orpheus TTS is English-only; the demo uses browser calls, not phone lines; the vector index is in memory. Next: telephony, streaming audio, CRM and calendar integrations, an evaluation suite (call-success rate, hallucination checks), and A/B testing of scripts.
