# Knowledge base (not ingested)

HelioNest Energy Pvt. Ltd. is a **fictional company** made up for this demo.
All names, prices, phone numbers, emails, offers and statistics in this folder are mock data.

The only real-world facts are the **PM Surya Ghar: Muft Bijli Yojana** subsidy rules
(central subsidy amounts, special-category states, scheme end date), which follow the
current government guidelines. They can change, so the agent always says so.

The RAG loader ingests every `.md` file in this folder **except this README**.
Each `##` section is written to stand on its own, because the loader splits chunks on `##` headings.
